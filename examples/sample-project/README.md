# サンプルプロジェクト（実習用Webアプリ）

> 学習の主目的はGit/GitHubです。コードは極力シンプルにしています。
> 構成： `index.html` `style.css` `script.js` のみ。ブラウザで `index.html` を開くだけで動きます。

## 使い方

```bash
# ブラウザで開く（ビルド不要）
start examples/sample-project/index.html
```

またはVS CodeのLive Serverでも可。

## 課題での使い方

- STEP 12 / SOLO-01： `<h1>` や自己紹介 `<section>` を1か所変える
- STEP 14： 検索フォームを追加する
- FINAL： 地域カードを追加する
