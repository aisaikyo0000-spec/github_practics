# オンボーディング（途中参加ガイド）

> いつ参加しても大丈夫です。Aさん（9/1開始・STEP 30）とBさん（9/20開始・STEP 8）の例で説明します。

## 手順（4ステップ）

1. **Repositoryを取得**

```bash
git clone https://github.com/aisaikyo0000-spec/github_practics.git
# 取得済みなら
git switch main
git pull origin main
```

2. **現在のmainを取得**（fetch→pull。STEP 11参照）
3. **自分の学習STEPを開始**（BさんはSTEP 1から順番に。追いつく必要なし）
4. **参加条件を満たしたらIssueを担当**（例：TEAM参加はSTEP 14完了後。空きIssueに立候補）

## 先行メンバーへのお願い

- Issueに背景・完了条件を丁寧に書く（後から来る人が読む）
- mainは常に動く状態に保つ
- 口頭決定はIssue/PRに転記する

## よくある質問

- Q: みんなに追いつかないとダメ？ A: 不要です。STEP順に進んでください
- Q: 古いSTEPの内容が変わっていたら？ A: mainをpullし直し、ROADMAPで差分を確認
