# チームルール

> 3人以上でも1人でも守れる最小ルールです。

1. **mainへの直接pushは禁止**（必ずBranch→PR→Merge）
2. **作業前にIssueを作る**（目的・背景・作業内容・完了条件を書く）
3. **1 Issue = 1 Branch = 1 PR**（大きくしない）
4. **PRにはテンプレートを使う**（`Closes #番号` を書く）
5. **他人レビュー1件以上でMerge**（1人の時はセルフレビュー＋チェックリスト）
6. **作業前に `git pull origin main`**（古いまま始めない）
7. **Branch名**： `feature/xxx` `fix/xxx` `docs/xxx`（必要なら `-ユーザー名`）
8. **Commitメッセージ**： 意味のある英語動詞始まり推奨（`Add...` `Fix...` `Update...`）。`fix` `aaa` 禁止
9. **非同期第一**： 口頭で済ませず文字に残す。進捗・依頼はIssue/PRに書く
