# SOLO-01: 自己紹介ページを作る（STEP 12–14対応）

## 目的

Issue→Branch→PR→Mergeを一人で完走する。

## 手順

1. 🌐 Issue作成： `自己紹介文を追加する`（4項目記載）
2. 💻 `git switch -c feature/self-intro-あなたのID`
3. 💻 `examples/sample-project/index.html` に自己紹介 `<section>` を追加
4. 💻 `git add/commit/push`（メッセージ例：`Add self-introduction section`）
5. 🌐 PR作成（テンプレ使用・`Closes #番号`）
6. 🌐 セルフレビュー（Files changedで誤字確認）
7. 🌐 Merge→Branch削除→mainをpull

## 完了条件

- [ ] PRがMergeされた
- [ ] mainで表示確認した

## ヒント

詰まったら [STEP 12](../../lessons/05-pull-request/STEP12-pr-flow.md) に戻ってください。
