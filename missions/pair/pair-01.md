# PAIR-01: Issue担当 × Review担当

## 役割

- A（Issue担当）： Issueを立てて実装・PR作成
- B（Review担当）： レビューしてApprove/Merge判断

次回は交代。

## 手順

1. 🌐 AがIssue作成（例：`検索フォームを追加`）
2. 💻 AがBranch→実装→Push→PR（`Closes #番号`、テンプレ使用）
3. 🌐 Bが3観点レビュー（良い点・問題点・提案）
4. 💻 Aが修正（必要なら）→ Bが再レビュー → Approve
5. 🌐 BまたはAがMerge（事前に決めておく）

## 完了条件

- [ ] PRがMergeされた
- [ ] 2人とも「担当」と「レビュー」を1回ずつ経験した（2周推奨）
- [ ] コメントが「OK」のみで終わらなかった

## 非同期のコツ

- レビュー依頼はPR上で `@相手ID review please` とメンション
- 修正依頼は具体的に（ファイル・行・理由を書く）
