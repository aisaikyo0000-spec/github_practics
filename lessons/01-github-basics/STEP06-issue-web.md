# STEP 6 — Issueを使ってみる（Web）

## 🎯 このLessonの目的

やること付箋（Issue）の作り方を覚え、PHASE 1を締めます。

## 📖 Learn

Issueは課題票です。本教材では必ずこの4項目を書きます：

- 目的・背景・作業内容・完了条件

```markdown
## 目的
## 背景
## 作業内容
## 完了条件
```

## 🖥 Try（🌐 Web・約10分）

1. 練習リポジトリで `Issues` タブ → `New issue`
2. タイトル： `hello.mdに見出しを追加する`
3. 本文：

```markdown
## 目的
自己紹介文を分かりやすくする
## 背景
現状1行だけで寂しいため
## 作業内容
- [ ] hello.mdに自己紹介を1行追加
## 完了条件
- mainに反映されていること
```

4. `Submit new issue`。Issue番号（例：`#1`）をメモ

## 💡 考えてみよう

- 口頭の「あれやっといて」とIssueの違いは何でしょう？（ヒント：人数可変・非同期）

## 🎯 Mission

- [ ] Issueを1件作成した
- [ ] IssueをCloseした（完了扱いにする体験）

## ✅ Check（PHASE 1 修了確認）

- [ ] アカウント・Repository・Commit・Branch・PR・Merge・Issueを一通り触った
- [ ] 分からない用語があっても手順を見返せば操作できる

## 🚨 Troubleshooting

- Issueが作れない → 練習リポジトリのIssues機能が無効かも。Settings → Features → Issuesにチェック
