# STEP 2 — RepositoryとREADMEを読む

## 🎯 このLessonの目的

Repository（書類箱）の構造と、README（案内板）の読み方を覚えます。

## 📖 Learn

Repositoryは1プロジェクト＝1箱です。中には：

- ファイル（コード・画像など）
- 履歴（誰がいつ変えたか）
- Issue・PR（相談・付箋）

が入っています。README.mdは箱の表に貼られた案内板で、最初に読む場所です。

## 🖥 Try（🌐 Web・約10分）

1. この教材リポジトリ `https://github.com/aisaikyo0000-spec/github_practics` を開く
2. トップのREADMEを読む（今読んでいる文章の本物です）
3. 上部のメニューを確認：
   - `<> Code`：ファイル一覧
   - `Issues`：付箋一覧
   - `Pull requests`：相談一覧
4. `lessons/00-start-here.md` をクリックして開く
5. 右上の `...` → `Copy path` やファイルの階層表示（パンくず）を確認

## 💡 考えてみよう

- なぜREADMEはリポジトリのトップに置くのでしょう？本の表紙と比べて考えてみてください。

## 🎯 Mission

教材リポジトリを「読むだけ」で探索し、以下を見つけてください：

- [ ] `examples/sample-project/README.md` を開いた
- [ ] `team/rules.md` を開いた
- [ ] Issuesタブを開いて件数を確認した（0件でもOK）

## ✅ Check

- [ ] Repositoryが「箱」、READMEが「案内板」と説明できる
- [ ] Code / Issues / Pull requests タブの場所が分かる
- [ ] ファイルの階層移動ができる

## 🚨 Troubleshooting

- 404になる → URLの綴り（`github_practics`）を確認。`s` の有無に注意
- 英語表示で怖い → ブラウザ翻訳可。操作ボタン位置だけ覚えればOK
