# STEP 1 — GitHubアカウントを作る

## 🎯 このLessonの目的

GitHubという「共有図書館」の利用者カードを作ります。これがないと何も始まりません。

## 📖 Learn

GitHubを使うには無料アカウントが必要です。メールアドレスが1つあれば作れます。
学生はStudent Packもありますが、まずは通常登録でOKです。

## 🖥 Try（🌐 Web・約5分）

1. https://github.com にアクセス
2. `Sign up` をクリック
3. メールアドレス・パスワード・ユーザー名を入力
   - ユーザー名は後から変えられますが、教材ではそのまま使います。メモしておきましょう
4. メールの認証コードを入力
5. アンケートはスキップ可。無料プラン（Free）を選択

## 💡 考えてみよう

- GitHubのユーザー名はチーム開発で「誰がやったか」の表示に使われます。読みやすい名前がおすすめなのはなぜでしょう？

## 🎯 Mission

- [ ] GitHubにログインできる
- [ ] 自分のプロフィールページ（`https://github.com/あなたのID`）を開ける

## ✅ Check（Checkpoint）

- [ ] アカウントを作成した
- [ ] ログイン状態を保持した（パスワード管理アプリ等に保存推奨）
- [ ] 二段階認証（2FA）を有効にした（推奨：Settings → Password and authentication）

## 🚨 Troubleshooting

- メールが届かない → 迷惑メールを確認、再送ボタンを使用
- ユーザー名が既に使われている → 数字やハイフンを足す（例：`taro-dev-2026`）
- 詳しくは [TROUBLESHOOTING](../TROUBLESHOOTING.md#github-authentication認証エラー) 参照
